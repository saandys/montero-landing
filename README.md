# Zapatería Montero 👞

Landing page developed with **Next.js** for *Zapatería Montero*, a local shoe repair shop focused mainly on **shoe repair and basic footwear services**.

The website is designed as a simple, clear, and fast **landing page**, providing only the essential information about the business.

---

## 🧾 Project Description

This website is an informational landing page created to:

* Present the business
* Show basic information about the services offered
* Provide contact and location details
* Improve the online presence of the shoe repair shop

It is not an e‑commerce platform or a complex application, but a lightweight and straightforward website.

---

## 🚀 Technologies Used

* **Next.js** – React framework for web applications
* **React** – User interface library
* **Tailwind CSS** – Utility‑first CSS framework for styling
* **HTML5**
* **JavaScript (ES6+)**

---

## ▶️ Installation and Development

To run the project locally:

```bash
npm install
npm run dev
```

Then open:

```
http://localhost:3000
```

---

## 📱 Responsive Design

The website is fully responsive and optimized for:

* Mobile devices
* Tablets
* Desktop screens
